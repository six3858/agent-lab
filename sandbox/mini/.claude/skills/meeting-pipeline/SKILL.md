# 회의록 파이프라인

입력: $ARGUMENTS (회의 메모 파일 경로)

1. 입력 파일을 Read로 읽는다.
2. 아래 4개 섹션으로 요약해 `out/summary.md`에 Write로 저장한다. 제목과 순서를 바꾸지 않는다.
   ## 결정사항 / ## 할 일 (표: 담당, 할 일, 기한) / ## 미해결 질문 / ## 한 줄 요약
   원문에 없는 담당자나 기한은 `미정`으로 쓴다.
3. fact-checker 서브에이전트에게 원문 경로와 `out/summary.md` 경로를 넘겨 대조시킨다.
4. 판정이 `수정 필요`이면 지적 사항만 반영해 `out/summary.md`를 한 번만 고친다. 다시 검수하지는 않는다.
5. 최종 보고: (a) 저장한 파일 경로 (b) fact-checker 판정과 핵심 지적 (c) 수정했다면 무엇을 고쳤는지.
